# Research spikes

For "investigate / feasibility / can we…" cards. The five stages still run, but they mean:

| Stage | For a spike |
| --- | --- |
| Scope | Define the question, the time box, and the decision the answer unlocks |
| POC | Run the investigation: throwaway scripts on a `spike/<slug>` branch, never merged |
| Implement | Write up the findings on the card, and create follow-up cards if it's actionable |
| QA | {{OWNER}} confirms the findings answer the question |
| Document | Keep anything worth keeping in the most specific `CLAUDE.md` or `docs/` file |

A spike produces no merged PR unless its write-up lands in the docs.
